# CaliberUX – 6 Screens

Screens: Suppliers, Analytics, Reports, Audit Logs, Alerts, Settings.
Plain HTML/CSS/JS – no install or build step needed.

## Run on localhost
Option 1 (Node.js):   `node server.js`   → http://localhost:3000
Option 2 (npm):       `npm start`
Option 3 (Python):    `python -m http.server 3000`  → http://localhost:3000

Pages: /suppliers.html /analytics.html /reports.html /audit-logs.html /alerts.html /settings.html
